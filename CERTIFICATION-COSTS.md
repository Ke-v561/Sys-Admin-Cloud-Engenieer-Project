# Certification costs

**US price snapshot: November 5, 2026.** Before taxes/fees; prices vary by region and may change.

| Certification | Price | Notes |
|---|---:|---|
| Microsoft AZ-900 | $99 | Optional foundation exam |
| CompTIA Security+ SY0-701 | $439 | Standard single-attempt voucher planning estimate; confirm at checkout |
| Microsoft AZ-104 | $165 | Primary Azure administrator exam |
| HashiCorp Terraform Associate 004 | $70.50 | Plus local taxes/fees; no free retake included |
| AWS SAA-C03 | $150 | Optional associate-level AWS exam |

## Budget scenarios
- Core path without AZ-900: **$674.50**
- Core path with AZ-900: **$773.50**
- Core plus AWS without AZ-900: **$824.50**
- Core plus AWS with AZ-900: **$923.50**

One attempt per exam only. Excludes retakes, books, courses, practice tests, equipment, electricity, internet, cloud consumption, and taxes. Voucher discounts and employer reimbursement may reduce cost.
