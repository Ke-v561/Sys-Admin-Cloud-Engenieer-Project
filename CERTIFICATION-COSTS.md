# Certification and cost planning

**Important:** prices and exam versions change by region and date. The amounts below are budgeting placeholders in USD, not verified checkout quotes. Confirm the current price, exam code, and objectives on the official provider page before paying.

| Credential | Role in roadmap | Planning allowance | Official page |
|---|---|---:|---|
| Microsoft AZ-900 | Optional fundamentals exam; learning content is still covered | $99 | https://learn.microsoft.com/credentials/certifications/azure-fundamentals/ |
| CompTIA Security+ | Optional security credential; security curriculum is mandatory | $400–$450 | https://www.comptia.org/certifications/security |
| Microsoft AZ-104 | Primary certification target | $165 | https://learn.microsoft.com/credentials/certifications/azure-administrator/ |
| HashiCorp Terraform Associate | Optional IaC credential | $70–$100 | https://developer.hashicorp.com/certifications/infrastructure-automation |
| AWS Solutions Architect Associate | Optional second-cloud credential | $150 | https://aws.amazon.com/certification/certified-solutions-architect-associate/ |

## Other possible costs
- Windows Server and Windows client licensing, depending on existing entitlements and evaluation use.
- Cloud consumption (VMs, disks, public IPs, storage, monitoring, bandwidth). Set budgets and alerts; delete resources after labs.
- Optional domain name, backup storage, or additional RAM/SSD if the existing host cannot run the required VMs.
- Retakes, taxes, practice exams, books, and training subscriptions.

## Cost-control rules
1. Prefer official free learning paths and local VMs.
2. Do not leave cloud VMs, disks, public IPs, or managed services running after a lab.
3. Set a budget/alert before creating billable cloud resources.
4. Use exam vouchers or employer reimbursement if available.
5. Do not buy new hardware until resource pressure is measured and documented.
