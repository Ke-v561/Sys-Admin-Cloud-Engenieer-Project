# Phase 10 — AWS extension

## Purpose
Only pursue this after the Azure capstone if target jobs ask for AWS or you want multi-cloud breadth. Learn AWS equivalents rather than repeating every Azure lab.

## End goal
Build and explain a small secure, resilient AWS architecture and compare its design to the Azure capstone.

## Prerequisites
- Phase 09 complete; only if AWS is relevant to target roles.

## Certification
**AWS Solutions Architect Associate optional.** Optional credential only after Azure capstone. Official page: https://aws.amazon.com/certification/certified-solutions-architect-associate/ .

## Estimated duration
**4–8 weeks** at 6–10 hours per week. Adjust based on demonstrated competence, not calendar pressure.

## Learning objectives and hands-on labs
1. Map Azure identity, networking, compute, storage, monitoring, and governance to AWS services.
2. Build a small VPC with subnets, routing, security groups, and a controlled compute workload.
3. Practice IAM roles/policies, S3 security/lifecycle, EC2, load balancing, scaling, and CloudWatch.
4. Create a resilient architecture using multiple Availability Zones and explain cost/reliability trade-offs.
5. Study the current AWS SAA exam guide and complete scenario-based practice.

## Final project
Build and explain a small secure, resilient AWS architecture and compare its design to the Azure capstone.

## Completion criteria
- [ ] Can map core Azure concepts to AWS equivalents.
- [ ] Can explain IAM, VPC, EC2, S3, load balancing, scaling, monitoring, and resilience.
- [ ] Can estimate costs and identify security risks.
- [ ] AWS exam is optional and not required for the Azure-first route.
