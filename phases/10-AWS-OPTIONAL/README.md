# Phase 10 — AWS extension

## Purpose
Optional second-cloud credential after Azure capstone or when target roles ask for AWS.

## Certification target
**AWS Certified Solutions Architect Associate SAA-C03 (optional)**

## Estimated duration
**8–12 weeks** at 8–10 hours/week, including learning, labs, review, exam preparation, and the exam.

## End goal
Build and explain secure, resilient, cost-aware AWS architecture; pass SAA-C03.

## Prerequisites
- Phase 09 complete; AWS account with budget controls.

## Official exam objectives
- SAA-C03 exam guide: https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-associate-03.html

## Hands-on lab objectives
1. Map Azure identity, networking, compute, storage, monitoring to AWS equivalents.
2. Build VPC with public/private subnets, routes, gateways, security groups, NACL concepts.
3. Configure IAM roles/policies and least privilege.
4. Deploy EC2 workload and secure S3 with lifecycle/access policy.
5. Design load balancing, scaling, multi-AZ resilience, backup, monitoring, disaster recovery.
6. Estimate costs and identify drivers.
7. Document Well-Architected trade-offs across security, reliability, performance, cost, operations.
8. Study current SAA-C03 exam guide and pass.

## Final project
Build and explain secure, resilient, cost-aware AWS architecture; pass SAA-C03.

## Completion criteria
- [ ] Can map Azure to AWS services.
- [ ] Can explain IAM, VPC, EC2, S3, load balancing, scaling, monitoring, resilience.
- [ ] Can justify architecture and cost.
- [ ] Pass SAA-C03.

## Exam readiness gate
- [ ] Current official exam domains reviewed.
- [ ] Mapped labs completed and documented.
- [ ] Can explain concepts without notes.
- [ ] Weak-area labs repeated without a walkthrough.
- [ ] Practice performance consistently meets personal readiness threshold.
- [ ] Exam version, price, policy, and prerequisites rechecked before booking.

## Cost and safety
Verify regional exam price at checkout. Set cloud budgets before deployment and remove resources afterward. Check OS licensing/evaluation terms. Never expose management services or publish secrets.
