# Phase 04 — Azure Administrator Associate (AZ-104)

## Phase purpose
Primary certification phase. Deploy, configure, secure, monitor, and maintain Azure resources, then prove the skills in a documented practical project.

## Credential and anticipated price
- **Credential:** Microsoft Certified: Azure Administrator Associate — AZ-104
- **Exam price:** $165 USD
- **Price snapshot:** November 5, 2026; before applicable taxes/fees. Confirm current price and exam version before purchase.
- **Other costs:** optional study materials, retakes, and cloud consumption are additional.

## Estimated duration
8–12 weeks at 6–10 study hours per week.

## Starting requirements
- Phases 00–03 complete.
- Practical OS, networking, server, virtualization, PowerShell, and identity knowledge.
- Familiarity with Azure portal and cloud concepts.
- Azure subscription with billing controls.

## Phase objectives
- Identity/governance: Entra users/groups, RBAC, subscriptions, resource groups, policies, locks, tags.
- Storage: accounts, redundancy, access, blobs/files, lifecycle, secure access.
- Compute: VMs, sizing, disks, availability, extensions, and services in current guide.
- Networking: VNets, subnets, peering, NSGs, DNS, routing, connectivity, troubleshooting.
- Monitoring/maintenance: Azure Monitor, alerts, logs, backup, recovery, resource health.

## End goal
Pass AZ-104 and independently administer a small Azure environment, explaining design, security, cost, monitoring, and recovery choices.

## Hands-on work
- Create resource-group and tagging strategy.
- Create Entra users/groups and assign least-privilege Azure RBAC.
- Deploy VNet, subnets, NSGs, and controlled connectivity.
- Deploy/administer Windows or Linux VM; configure disks and secure access.
- Create storage account with suitable redundancy/access controls.
- Configure monitoring, diagnostics, alerts, and backup/recovery.
- Use PowerShell and Azure CLI.
- Estimate costs and tear down lab resources.

## Final project
Deploy a secure, monitored, cost-conscious Azure workload for a fictional small business. Include architecture, identity/RBAC, network, compute/storage, monitoring/backup, scripts, cost estimate, and cleanup proof.

## Completion requirements
- Map every current AZ-104 objective to notes and lab evidence.
- Complete Microsoft Learn AZ-104 modules.
- Rebuild final project from a clean resource group using your own steps.
- Troubleshoot identity, network, compute, storage, and monitoring scenarios.
- Complete official practice assessment and remediate gaps.
- 85%+ on fresh practice sets is a readiness heuristic.
- Pass AZ-104 and record credential.

## Exam / skills alignment
Official areas: Manage Azure identities and governance; implement/manage storage; deploy/manage compute; implement/manage virtual networking; monitor/maintain Azure resources. Check current study guide for detailed weights.
