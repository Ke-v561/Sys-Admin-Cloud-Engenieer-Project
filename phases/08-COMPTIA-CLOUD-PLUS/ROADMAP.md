# Phase 8 — CompTIA Cloud+

**Outcome:** Consolidate vendor-neutral cloud architecture, deployment, operations, security, and troubleshooting knowledge.

## Official preparation
- Certification and current objectives: https://www.comptia.org/certifications/cloud

Download the current exam objectives for the exam version you plan to take. Map every objective to a note, lab, or documented explanation. Cloud+ is an intermediate-level credential; hands-on systems and cloud experience will make the material more meaningful.

## Project 8.1 — End-to-end cloud solution design

Scenario: A small company needs to move an internal application and file service from an on-premises environment to cloud infrastructure.

Document:
- Requirements and assumptions.
- Architecture diagram.
- Compute, network, and storage choices.
- Identity and security controls.
- Monitoring and alerting.
- Backup and recovery.
- Cost considerations.
- Deployment, validation, and rollback.
- Operational runbook.

## Project 8.2 — Infrastructure as code
1. Expand the Azure Bicep or equivalent deployment.
2. Store source in GitHub.
3. Parameterize environment-specific values.
4. Deploy into a test environment.
5. Validate the resulting resources.
6. Make a controlled change and document rollback.

## Project 8.3 — Multi-cloud troubleshooting
Compare an Azure and AWS investigation for a VM/workload that cannot communicate with another system. Identify equivalent concepts, diagnostic tools, identity controls, network controls, and verification steps.
