# Phase 03 — Security Foundations (CompTIA Security+)

## Phase purpose
Certification phase. Cloud engineers must understand identity, risk, secure configuration, network defense, vulnerability management, incident response, and governance. Security+ provides a vendor-neutral baseline before cloud administration.

## Credential and anticipated price
- **Credential:** CompTIA Security+ — SY0-701
- **Exam price:** $439 USD planning estimate for one standard US exam attempt; confirm current voucher price at checkout.
- **Price snapshot:** November 5, 2026; before applicable taxes/fees. Confirm current price and exam version before purchase.
- **Other costs:** optional study materials, retakes, and cloud consumption are additional.

## Estimated duration
6–10 weeks at 6–10 study hours per week.

## Starting requirements
- Phases 00 and 02 complete.
- Basic networking, Windows administration, and command-line familiarity.

## Phase objectives
- Security concepts: CIA triad, risk, threats, vulnerabilities, control types, architecture.
- Threats and vulnerabilities: attack vectors, malware, social engineering, vulnerability management, secure configuration.
- Architecture: segmentation, secure network design, cloud/shared responsibility, resilience, data protection.
- Operations: logging, monitoring, incident response, access control, endpoint security, remediation.
- Program management: policies, risk, compliance, awareness, third-party risk.
- Identity: MFA, least privilege, RBAC, federation, privileged access, lifecycle.

## End goal
Pass Security+ and demonstrate selection, implementation, monitoring, and explanation of security controls in a small lab.

## Hands-on work
- Harden Windows Server/client with documented lab baseline.
- Separate standard and administrative test accounts.
- Configure auditing and review security logs.
- Create threat model and map threats to controls.
- Practice synthetic incident triage and response checklist.
- Review firewall rules by source, destination, port, and purpose.
- Document backup, recovery, patching, and remediation.

## Final project
Secure Small Business Lab package: asset inventory, threat model, privilege matrix, hardening checklist, firewall rationale, logging/incident runbook, and recovery test.

## Completion requirements
- Cover all current SY0-701 objectives.
- Review reasoning for every missed practice question.
- Demonstrate least privilege, logging, segmentation, patching, backup, and incident response.
- Use 85%+ on fresh practice sets as a planning heuristic, not a guarantee.
- Pass exam and record credential.

## Exam / skills alignment
Current domains: General Security Concepts; Threats, Vulnerabilities, and Mitigations; Security Architecture; Security Operations; Security Program Management and Oversight. Official objectives are definitive.
