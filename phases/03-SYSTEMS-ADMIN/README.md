# Phase 03 — Windows Server systems administration

## Purpose
Complete AZ-802 preparation: Windows Server workloads, hybrid management, compute, storage/file services, security, monitoring, and troubleshooting.

## Certification target
**Complete AZ-802 preparation and pass Windows Server Administrator Associate**

## Estimated duration
**5–7 weeks** at 8–10 hours/week, including learning, labs, review, exam preparation, and the exam.

## End goal
Operate a member/file server with permissions, patching, monitoring, backup/restore, PowerShell, and incident runbooks; pass AZ-802.

## Prerequisites
- Phase 02 complete; enough resources for member server if possible; otherwise run one role at a time.

## Official exam objectives
- AZ-802: https://learn.microsoft.com/credentials/certifications/exams/az-802/

## Hands-on lab objectives
1. Add second Windows Server member/file-server VM if resources allow.
2. Create SMB shares; apply share and NTFS permissions through groups; test allowed/denied access.
3. Manage server roles, services, scheduled tasks, remote administration, and Windows Admin Center concepts.
4. Write PowerShell for inventory, service checks, synthetic user/group administration, event collection, and disk reporting.
5. Apply updates with pre-check, maintenance window, post-check, and rollback notes.
6. Configure backup/System State or supported lab backup; restore files and document recovery objectives.
7. Review Hyper-V/VM management, storage, networking, secure configuration, Azure Arc/Azure Monitor concepts, and hybrid administration per AZ-802 guide.
8. Write runbooks for stopped service, full disk, inaccessible share, failed patch, DNS outage, and locked account.
9. Complete practice assessment and pass AZ-802.

## Final project
Operate a member/file server with permissions, patching, monitoring, backup/restore, PowerShell, and incident runbooks; pass AZ-802.

## Completion criteria
- [ ] Can manage file services and explain share vs NTFS permissions.
- [ ] Can troubleshoot services, storage, updates, performance, and remote administration.
- [ ] Can explain and safely run PowerShell scripts.
- [ ] Can restore data and document recovery.
- [ ] Pass AZ-802.

## Exam readiness gate
- [ ] Current official exam domains reviewed.
- [ ] Mapped labs completed and documented.
- [ ] Can explain concepts without notes.
- [ ] Weak-area labs repeated without a walkthrough.
- [ ] Practice performance consistently meets personal readiness threshold.
- [ ] Exam version, price, policy, and prerequisites rechecked before booking.

## Cost and safety
Verify regional exam price at checkout. Set cloud budgets before deployment and remove resources afterward. Check OS licensing/evaluation terms. Never expose management services or publish secrets.
