# Lab checklist — Windows Server systems administration

- [ ] Add second Windows Server member/file-server VM if resources allow.
- [ ] Create SMB shares; apply share and NTFS permissions through groups; test allowed/denied access.
- [ ] Manage server roles, services, scheduled tasks, remote administration, and Windows Admin Center concepts.
- [ ] Write PowerShell for inventory, service checks, synthetic user/group administration, event collection, and disk reporting.
- [ ] Apply updates with pre-check, maintenance window, post-check, and rollback notes.
- [ ] Configure backup/System State or supported lab backup; restore files and document recovery objectives.
- [ ] Review Hyper-V/VM management, storage, networking, secure configuration, Azure Arc/Azure Monitor concepts, and hybrid administration per AZ-802 guide.
- [ ] Write runbooks for stopped service, full disk, inaccessible share, failed patch, DNS outage, and locked account.
- [ ] Complete practice assessment and pass AZ-802.
