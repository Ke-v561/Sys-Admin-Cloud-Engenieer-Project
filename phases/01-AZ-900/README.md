# Phase 01 — Cloud Fundamentals (AZ-900)

## Phase purpose
Certification phase. Establish cloud vocabulary and understand Azure services before role-based administration. AZ-900 is recommended for structured learning and an entry credential, but it is not a mandatory prerequisite for AZ-104.

## Credential and anticipated price
- **Credential:** Microsoft Certified: Azure Fundamentals — AZ-900
- **Exam price:** $99 USD
- **Price snapshot:** November 5, 2026; before applicable taxes/fees. Confirm current price and exam version before purchase.
- **Other costs:** optional study materials, retakes, and cloud consumption are additional.

## Estimated duration
2–4 weeks at 6–10 study hours per week.

## Starting requirements
- Phase 00 complete.
- Basic IT infrastructure concepts.
- No prior Azure experience required.

## Phase objectives
- Cloud computing, shared responsibility, consumption pricing, CapEx/OpEx, public/private/hybrid cloud, IaaS/PaaS/SaaS.
- Azure regions, availability zones, subscriptions, resource groups, management groups.
- Core compute, networking, storage, database, and identity services.
- Management, governance, security, compliance, and cost tools.

## End goal
Pass AZ-900 if pursuing it and explain Azure service families well enough to select services for simple scenarios.

## Hands-on work
- Complete official AZ-900 learning paths.
- Navigate tenant, subscription, resource group, and resource relationships.
- Explore Entra ID, VNets, VMs, storage accounts, and Azure Monitor conceptually or with controlled low-cost labs.
- Classify sample solutions as IaaS/PaaS/SaaS.

## Final project
Design a one-page Azure landing-zone concept for a small business: tenant, subscription, resource groups, network, compute, storage, identity, governance, monitoring, and cost controls.

## Completion requirements
- Complete official learning paths and practice assessment.
- Review every missed objective.
- Explain all three official skill areas without notes.
- If taking exam, pass AZ-900 and record credential URL.

## Exam / skills alignment
Official domains: Describe cloud concepts; Describe Azure architecture and services; Describe Azure management and governance. Check live study guide for exact weighting.
