# Phase 9 — Career Portfolio and Job Readiness

**Outcome:** Present credible evidence of your ability to support and administer systems and cloud infrastructure.

## Portfolio minimum
Publish at least three polished case studies:
1. Windows domain services: AD DS, DNS, users/groups, GPO, and troubleshooting.
2. PowerShell administration toolkit: scripts, safe tests, sample outputs, and explanations.
3. Azure infrastructure: identity, networking, compute/storage, monitoring, and cleanup.

Optional fourth case study: cloud incident and recovery exercise.

## Each case study should include
- Business-style problem statement.
- Architecture or topology diagram.
- Environment and tools.
- Implementation steps.
- Validation evidence.
- Troubleshooting/root cause.
- Security and cost considerations.
- Lessons learned.

## Resume rules
- List only skills you can explain and demonstrate.
- Separate professional experience from home-lab projects.
- Do not describe lab experience as production experience.
- Include links to relevant repositories or case studies.
- Tailor the resume to each job description.

## Target roles by demonstrated capability
- Windows/networking foundation: Junior Systems Administrator, IT Infrastructure Support.
- Windows + PowerShell: Systems Administrator I, Technical Support Engineer.
- Azure administration evidence: Cloud Support Engineer, Azure Support Administrator, Cloud Operations.
- Multi-cloud and operations: Junior Cloud Engineer roles where experience requirements fit.

## Interview preparation
Prepare concise STAR stories for:
- A difficult troubleshooting issue.
- A permissions or identity problem.
- A network/DNS issue.
- An automation task.
- A failed deployment and recovery.
- A security or cost decision.

## Acceptance criteria
- [ ] Three case studies published
- [ ] Project index updated
- [ ] Resume updated with defensible skills
- [ ] Five interview stories prepared
- [ ] Job search targets reviewed monthly
