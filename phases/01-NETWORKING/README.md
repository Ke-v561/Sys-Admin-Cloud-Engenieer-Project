# Phase 01 — Networking foundations

## Purpose
Prepare for a networking certification and build the foundations for AD DS and cloud networking. Choose one exam.

## Certification target
**CompTIA Network+ N10-009 (default) OR Cisco CCNA (alternative)**

## Estimated duration
**6–8 weeks** at 8–10 hours/week, including learning, labs, review, exam preparation, and the exam.

## End goal
Deliver a segmented lab network with an address plan, DNS/DHCP configuration, firewall rules, and troubleshooting evidence.

## Prerequisites
- Phase 00 complete; basic command-line familiarity.

## Official exam objectives
- Network+: https://www.comptia.org/certifications/network
- CCNA: https://www.cisco.com/site/us/en/learn/training-certifications/certifications/enterprise/ccna/index.html

## Hands-on lab objectives
1. Build an IPv4/CIDR subnetting workbook: network, broadcast, usable range, gateway, and routes.
2. Create an isolated subnet with static IPs and documented DNS/gateway.
3. Configure DHCP scope, exclusions, reservations, leases, and DNS options.
4. Create DNS A/CNAME/PTR records and forwarders; test forward/reverse resolution.
5. Use ping, tracert, ipconfig, nslookup, route print, Test-NetConnection, and Wireshark to isolate DNS/routing/port failures.
6. Create firewall rules and prove allowed/blocked traffic.
7. CCNA alternative: add VLANs, trunks, inter-VLAN routing, static routes, and basic OSPF using Packet Tracer or supported lab gear.
8. Map study to current official objectives and pass Network+ or CCNA.

## Final project
Deliver a segmented lab network with an address plan, DNS/DHCP configuration, firewall rules, and troubleshooting evidence.

## Completion criteria
- [ ] Can subnet common CIDRs.
- [ ] Can explain DNS resolution and DHCP DORA.
- [ ] Can distinguish DNS, routing, and firewall faults with evidence.
- [ ] Pass selected networking exam.

## Exam readiness gate
- [ ] Current official exam domains reviewed.
- [ ] Mapped labs completed and documented.
- [ ] Can explain concepts without notes.
- [ ] Weak-area labs repeated without a walkthrough.
- [ ] Practice performance consistently meets personal readiness threshold.
- [ ] Exam version, price, policy, and prerequisites rechecked before booking.

## Cost and safety
Verify regional exam price at checkout. Set cloud budgets before deployment and remove resources afterward. Check OS licensing/evaluation terms. Never expose management services or publish secrets.
