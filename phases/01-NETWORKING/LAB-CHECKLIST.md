# Lab checklist — Networking foundations

- [ ] Build an IPv4/CIDR subnetting workbook: network, broadcast, usable range, gateway, and routes.
- [ ] Create an isolated subnet with static IPs and documented DNS/gateway.
- [ ] Configure DHCP scope, exclusions, reservations, leases, and DNS options.
- [ ] Create DNS A/CNAME/PTR records and forwarders; test forward/reverse resolution.
- [ ] Use ping, tracert, ipconfig, nslookup, route print, Test-NetConnection, and Wireshark to isolate DNS/routing/port failures.
- [ ] Create firewall rules and prove allowed/blocked traffic.
- [ ] CCNA alternative: add VLANs, trunks, inter-VLAN routing, static routes, and basic OSPF using Packet Tracer or supported lab gear.
- [ ] Map study to current official objectives and pass Network+ or CCNA.
