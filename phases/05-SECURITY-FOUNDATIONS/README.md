# Phase 05 — Security foundations

## Purpose
Build security practices into administration: least privilege, MFA, identity lifecycle, secure baselines, vulnerability/patch management, encryption, network segmentation, logging, incident response, backup resilience, and risk.

## End goal
Produce a security baseline and incident-response runbook for the home lab.

## Prerequisites
- Phases 01–04 complete; isolated lab and backups.

## Certification
**Security+ optional.** Optional exam. Security knowledge and labs are mandatory. Official page: https://www.comptia.org/certifications/security .

## Estimated duration
**3–5 weeks** at 6–10 hours per week. Adjust based on demonstrated competence, not calendar pressure.

## Learning objectives and hands-on labs
1. Harden the lab using a baseline checklist and document before/after state.
2. Create separate standard and admin accounts; test least privilege.
3. Apply MFA where available and document recovery methods.
4. Create firewall rules that allow only required traffic; validate with connection tests.
5. Review Windows security logs and build a simple incident timeline.
6. Run a tabletop incident: compromised account or ransomware; isolate, preserve evidence, restore, and communicate.
7. Study the current Security+ objectives if pursuing the certification.

## Final project
Produce a security baseline and incident-response runbook for the home lab.

## Completion criteria
- [ ] Can explain least privilege, MFA, segmentation, patching, encryption, and logging.
- [ ] Can identify and investigate suspicious sign-in/activity in lab logs.
- [ ] Can describe containment, eradication, recovery, and lessons learned.
