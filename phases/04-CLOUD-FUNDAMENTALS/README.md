# Phase 04 — Cloud fundamentals

## Purpose
Learn cloud concepts and Azure core services before cloud administration.

## Certification target
**Microsoft Azure Fundamentals AZ-900**

## Estimated duration
**3–4 weeks** at 8–10 hours/week, including learning, labs, review, exam preparation, and the exam.

## End goal
Deliver Azure fundamentals architecture and cost worksheet; pass AZ-900.

## Prerequisites
- Phases 01–03 complete; Microsoft account.

## Official exam objectives
- AZ-900: https://learn.microsoft.com/credentials/certifications/azure-fundamentals/

## Hands-on lab objectives
1. Map home lab components to cloud equivalents.
2. Study shared responsibility, IaaS/PaaS/SaaS, regions/zones, subscriptions, resource groups, and cloud models.
3. Draw Azure architecture with identity, network, compute, storage, governance, monitoring.
4. Explore portal and Microsoft Learn; set budget/alert before any billable resource.
5. Estimate costs for VM, disk, storage, and network.
6. Complete practice assessment and pass AZ-900.

## Final project
Deliver Azure fundamentals architecture and cost worksheet; pass AZ-900.

## Completion criteria
- [ ] Can explain cloud models and shared responsibility.
- [ ] Can distinguish region, zone, subscription, resource group, and management group.
- [ ] Can identify Azure identity, compute, storage, network, governance, and cost services.
- [ ] Pass AZ-900.

## Exam readiness gate
- [ ] Current official exam domains reviewed.
- [ ] Mapped labs completed and documented.
- [ ] Can explain concepts without notes.
- [ ] Weak-area labs repeated without a walkthrough.
- [ ] Practice performance consistently meets personal readiness threshold.
- [ ] Exam version, price, policy, and prerequisites rechecked before booking.

## Cost and safety
Verify regional exam price at checkout. Set cloud budgets before deployment and remove resources afterward. Check OS licensing/evaluation terms. Never expose management services or publish secrets.
