# Phase 04 — Cloud fundamentals

## Purpose
Translate infrastructure concepts into cloud concepts: shared responsibility, IaaS/PaaS/SaaS, regions/zones, subscriptions, resource groups, identity, compute, storage, networking, governance, pricing, and support.

## End goal
Explain cloud service models and design a basic Azure landing-zone sketch with identity, network, governance, and cost considerations.

## Prerequisites
- Phases 01–03 complete; Microsoft account. Azure subscription is optional for introductory learning.

## Certification
**AZ-900 optional.** Optional exam. Learning content is mandatory; the exam is not. Official page: https://learn.microsoft.com/credentials/certifications/azure-fundamentals/ .

## Estimated duration
**2–3 weeks** at 6–10 hours per week. Adjust based on demonstrated competence, not calendar pressure.

## Learning objectives and hands-on labs
1. Map your on-prem lab components to Azure equivalents.
2. Create a cloud architecture diagram for a small business workload.
3. Explore Microsoft Learn AZ-900 learning paths and official skills outline.
4. Estimate costs for a small VM, disk, network, and storage; identify cost drivers.
5. If using Azure, create a budget/alert and a resource group; verify cleanup.

## Final project
Explain cloud service models and design a basic Azure landing-zone sketch with identity, network, governance, and cost considerations.

## Completion criteria
- [ ] Can explain shared responsibility and service models.
- [ ] Can distinguish region, availability zone, subscription, and resource group.
- [ ] Can explain basic Azure identity, compute, storage, networking, and governance.
- [ ] AZ-900 exam is optional; sit only if useful for confidence or employer screening.
