# Phase 01 — Networking foundations

## Purpose
Understand the network services that make domains and cloud networks work: IPv4, subnetting, routing, switching, VLAN concepts, DNS, DHCP, NAT, firewalls, ports, TCP/UDP, VPNs, and packet troubleshooting.

## End goal
Build a working isolated subnet with documented addressing, DHCP/DNS behavior, and troubleshooting evidence.

## Prerequisites
- Phase 00 complete; basic Windows command-line familiarity.

## Certification
**None.** No certification required.

## Estimated duration
**3–5 weeks** at 6–10 hours per week. Adjust based on demonstrated competence, not calendar pressure.

## Learning objectives and hands-on labs
1. Draw the home-lab topology and address plan.
2. Calculate subnet ranges, gateways, and usable addresses for several CIDRs.
3. Build an isolated lab subnet and configure static addressing.
4. Configure DHCP scope/reservations and DNS forward/reverse records (in lab).
5. Use ping, tracert, nslookup, ipconfig, Test-NetConnection, and Wireshark to diagnose DNS, routing, and port failures.
6. Document a DNS failure and a blocked-port failure with evidence.

## Final project
Build a working isolated subnet with documented addressing, DHCP/DNS behavior, and troubleshooting evidence.

## Completion criteria
- [ ] Can subnet without a calculator for common sizes.
- [ ] Can explain DNS resolution and DHCP DORA.
- [ ] Can distinguish routing, DNS, and firewall failures.
- [ ] Can prove a service is reachable or blocked using more than ping.
