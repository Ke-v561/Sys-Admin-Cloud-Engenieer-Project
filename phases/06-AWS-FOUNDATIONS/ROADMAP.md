## Azure-to-AWS service map

| Capability | Azure | AWS |
|---|---|---|
| Virtual machines | Azure Virtual Machines | Amazon EC2 |
| Object storage | Blob Storage | Amazon S3 |
| Virtual network | Azure Virtual Network | Amazon VPC |
| Identity/permissions | Entra ID + Azure RBAC | AWS IAM |
| Monitoring | Azure Monitor | Amazon CloudWatch |
| Managed relational database | Azure SQL Database | Amazon RDS |

Services differ in design and behavior; do not assume they are interchangeable.

## Project 6.1 — Secure AWS account foundation
1. Protect the account with MFA.
2. Learn the root-user safety model.
3. Explore IAM users, roles, and policies.
4. Apply least privilege in a controlled environment.
5. Review billing and account security settings.

## Project 6.2 — Small AWS exploration lab
Explore EC2, S3, VPC, and CloudWatch. Deploy only a small controlled resource if pricing and permissions are understood. Record configuration and clean up afterward.
