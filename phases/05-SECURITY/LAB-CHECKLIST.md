# Lab checklist — Security foundations

- [ ] Create standard/admin accounts; test least privilege and separation of duties.
- [ ] Configure MFA where available and document recovery.
- [ ] Apply Windows security baseline and record validation.
- [ ] Segment lab network and prove allowed/blocked traffic.
- [ ] Investigate Windows security events and create incident timeline.
- [ ] Perform safe vulnerability/patch review and remediate findings.
- [ ] Run compromised-account/ransomware tabletop: identify, contain, eradicate, recover, lessons learned.
- [ ] Test backup restore and explain RPO/RTO, encryption, resilience.
- [ ] Map work to current Security+ objectives; pass current exam.
