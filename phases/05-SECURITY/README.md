# Phase 05 — Security foundations

## Purpose
Build security into systems administration and prepare for Security+.

## Certification target
**CompTIA Security+ (current version at booking)**

## Estimated duration
**6–8 weeks** at 8–10 hours/week, including learning, labs, review, exam preparation, and the exam.

## End goal
Produce security baseline, access matrix, event investigation, recovery test, and incident-response runbook; pass Security+.

## Prerequisites
- Phases 01–04 complete; isolated lab and working backups.

## Official exam objectives
- Security+: https://www.comptia.org/certifications/security

## Hands-on lab objectives
1. Create standard/admin accounts; test least privilege and separation of duties.
2. Configure MFA where available and document recovery.
3. Apply Windows security baseline and record validation.
4. Segment lab network and prove allowed/blocked traffic.
5. Investigate Windows security events and create incident timeline.
6. Perform safe vulnerability/patch review and remediate findings.
7. Run compromised-account/ransomware tabletop: identify, contain, eradicate, recover, lessons learned.
8. Test backup restore and explain RPO/RTO, encryption, resilience.
9. Map work to current Security+ objectives; pass current exam.

## Final project
Produce security baseline, access matrix, event investigation, recovery test, and incident-response runbook; pass Security+.

## Completion criteria
- [ ] Can explain least privilege, MFA, encryption, segmentation, patching, logging.
- [ ] Can investigate security events and build timeline.
- [ ] Can explain incident response and recovery.
- [ ] Can validate backup restore.
- [ ] Pass current Security+ exam.

## Exam readiness gate
- [ ] Current official exam domains reviewed.
- [ ] Mapped labs completed and documented.
- [ ] Can explain concepts without notes.
- [ ] Weak-area labs repeated without a walkthrough.
- [ ] Practice performance consistently meets personal readiness threshold.
- [ ] Exam version, price, policy, and prerequisites rechecked before booking.

## Cost and safety
Verify regional exam price at checkout. Set cloud budgets before deployment and remove resources afterward. Check OS licensing/evaluation terms. Never expose management services or publish secrets.
