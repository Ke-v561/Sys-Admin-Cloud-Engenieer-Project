# Lab checklist — Cloud engineering capstone and specialization

- [ ] Design Azure workload with identity, segmented network, compute, storage, monitoring, backup, least privilege.
- [ ] Deploy with Terraform or Bicep and document reproducible inputs.
- [ ] AZ-400 track: implement GitHub source control, CI/CD pipeline, validation, approvals, deployment, rollback, security, instrumentation.
- [ ] AZ-305 track: document architecture decisions for identity, network, reliability, security, governance, data, and cost; compare design alternatives.
- [ ] Configure logs, alerts, backup, recovery, tags, budget, cleanup.
- [ ] Simulate blocked network, denied permission, unhealthy service; collect evidence and resolve.
- [ ] Write architecture diagram, README, deployment guide, runbooks, incident reports, cost estimate, teardown.
- [ ] Study selected current official exam guide and pass AZ-400 or AZ-305.
