# Phase 09 — Cloud engineering capstone and specialization

## Purpose
Combine skills into production-style portfolio project and complete one advanced specialization. AZ-400 is DevOps/delivery automation; AZ-305 is solution architecture. Verify prerequisites before booking.

## Certification target
**Choose AZ-400 DevOps Engineer Expert OR AZ-305 Azure Solutions Architect Expert**

## Estimated duration
**8–10 weeks** at 8–10 hours/week, including learning, labs, review, exam preparation, and the exam.

## End goal
Deliver reproducible cloud environment and portfolio; earn one advanced specialization.

## Prerequisites
- Phases 01–08 complete; choose specialization and confirm prerequisites.

## Official exam objectives
- AZ-400: https://learn.microsoft.com/credentials/certifications/exams/az-400/
- AZ-305: https://learn.microsoft.com/credentials/certifications/exams/az-305/
- Verify current expert certification prerequisites before booking.

## Hands-on lab objectives
1. Design Azure workload with identity, segmented network, compute, storage, monitoring, backup, least privilege.
2. Deploy with Terraform or Bicep and document reproducible inputs.
3. AZ-400 track: implement GitHub source control, CI/CD pipeline, validation, approvals, deployment, rollback, security, instrumentation.
4. AZ-305 track: document architecture decisions for identity, network, reliability, security, governance, data, and cost; compare design alternatives.
5. Configure logs, alerts, backup, recovery, tags, budget, cleanup.
6. Simulate blocked network, denied permission, unhealthy service; collect evidence and resolve.
7. Write architecture diagram, README, deployment guide, runbooks, incident reports, cost estimate, teardown.
8. Study selected current official exam guide and pass AZ-400 or AZ-305.

## Final project
Deliver reproducible cloud environment and portfolio; earn one advanced specialization.

## Completion criteria
- [ ] Reviewer can reproduce deployment.
- [ ] Architecture covers identity, networking, compute, storage, security, monitoring, backup, cost.
- [ ] Three failure scenarios documented with root cause/prevention.
- [ ] Can defend design/operational trade-offs.
- [ ] Pass selected advanced exam.

## Exam readiness gate
- [ ] Current official exam domains reviewed.
- [ ] Mapped labs completed and documented.
- [ ] Can explain concepts without notes.
- [ ] Weak-area labs repeated without a walkthrough.
- [ ] Practice performance consistently meets personal readiness threshold.
- [ ] Exam version, price, policy, and prerequisites rechecked before booking.

## Cost and safety
Verify regional exam price at checkout. Set cloud budgets before deployment and remove resources afterward. Check OS licensing/evaluation terms. Never expose management services or publish secrets.
