# Phase 02 — Windows Server and Active Directory

## Purpose
Build a fresh domain and prepare the AD DS portion of Windows Server Administrator Associate. The exam is taken after Phase 03.

## Certification target
**AZ-802 preparation — part 1**

## Estimated duration
**6–8 weeks** at 8–10 hours/week, including learning, labs, review, exam preparation, and the exam.

## End goal
Rebuild a small Windows domain with identity design, OUs, groups, GPOs, DNS, joined client, and troubleshooting runbook.

## Prerequisites
- Phases 00–01 complete; Windows Server media and isolated virtual network.

## Official exam objectives
- AZ-802: https://learn.microsoft.com/credentials/certifications/exams/az-802/
- Windows Server Administrator Associate: https://learn.microsoft.com/credentials/certifications/windows-server-hybrid-administrator/

## Hands-on lab objectives
1. Build a fresh Windows Server VM on isolated network; configure static IP, hostname, time, and DNS.
2. Install AD DS and promote a new forest using private namespace such as corp.example.test.
3. Create OUs for users, workstations, servers, and groups; design delegation.
4. Create synthetic users, security groups, service accounts, and separate admin accounts; apply least privilege.
5. Join Windows client to domain and test logon, secure channel, and resource access.
6. Create GPOs for account policy, workstation hardening, mapped drives, and a test setting; validate with gpresult.
7. Configure DNS zones/records; troubleshoot registration and domain join failures.
8. Study Kerberos, time sync, lockouts, authentication events, and common identity failures.
9. Map AD DS tasks to current AZ-802 official objectives.

## Final project
Rebuild a small Windows domain with identity design, OUs, groups, GPOs, DNS, joined client, and troubleshooting runbook.

## Completion criteria
- [ ] Can install/promote AD DS independently.
- [ ] Can manage users/groups/OUs and delegate safely.
- [ ] Can troubleshoot DNS, domain join, GPO, lockout, and authentication.
- [ ] Can explain AD DS, DNS, Kerberos, GPO, and least privilege.

## Exam readiness gate
- [ ] Current official exam domains reviewed.
- [ ] Mapped labs completed and documented.
- [ ] Can explain concepts without notes.
- [ ] Weak-area labs repeated without a walkthrough.
- [ ] Practice performance consistently meets personal readiness threshold.
- [ ] Exam version, price, policy, and prerequisites rechecked before booking.

Verify regional exam price at checkout. Set cloud budgets before deployment and remove resources afterward. Check OS licensing/evaluation terms. Never expose management services or publish secrets.
