# Lab checklist — Windows Server and Active Directory

- [ ] Build a fresh Windows Server VM on isolated network; configure static IP, hostname, time, and DNS.
- [ ] Install AD DS and promote a new forest using private namespace such as corp.example.test.
- [ ] Create OUs for users, workstations, servers, and groups; design delegation.
- [ ] Create synthetic users, security groups, service accounts, and separate admin accounts; apply least privilege.
- [ ] Join Windows client to domain and test logon, secure channel, and resource access.
- [ ] Create GPOs for account policy, workstation hardening, mapped drives, and a test setting; validate with gpresult.
- [ ] Configure DNS zones/records; troubleshoot registration and domain join failures.
- [ ] Study Kerberos, time sync, lockouts, authentication events, and common identity failures.
- [ ] Map AD DS tasks to current AZ-802 official objectives.
