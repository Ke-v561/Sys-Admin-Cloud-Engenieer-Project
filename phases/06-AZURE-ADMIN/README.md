# Phase 06 — Azure administration

## Purpose
Primary cloud-admin certification: identity/governance, storage, compute, virtual networking, monitoring, backup, and automation.

## Certification target
**Microsoft Azure Administrator Associate AZ-104**

## Estimated duration
**12–16 weeks** at 8–10 hours/week, including learning, labs, review, exam preparation, and the exam.

## End goal
Deploy secure, monitored, cost-controlled Azure environment with identity, network, compute, storage, backup, automation, and troubleshooting evidence; pass AZ-104.

## Prerequisites
- Phases 01–05 complete; Azure subscription with budget/alerts; PowerShell/network basics.

## Official exam objectives
- AZ-104 study guide: https://learn.microsoft.com/credentials/certifications/resources/study-guides/az-104
- Certification/exam: https://learn.microsoft.com/credentials/certifications/exams/az-104/

## Hands-on lab objectives
1. Create dedicated subscription/resource group; configure MFA, RBAC, tags, budgets, alerts, and locks.
2. Manage Entra users/groups and assign roles at correct scopes; test least privilege.
3. Build VNets, subnets, peering concepts, NSGs, routes, DNS, and secure connectivity.
4. Deploy/manage VMs, disks, images, extensions, availability, boot diagnostics, and backup.
5. Create storage accounts, Blob/Azure Files, access controls, redundancy, lifecycle, and secure transfer.
6. Configure Azure Monitor, Log Analytics, diagnostics, alerts, resource health, and activity logs.
7. Automate admin tasks with Azure CLI and PowerShell.
8. Deploy resources with Bicep/ARM templates and parameters.
9. Perform backup/recovery test and resource cleanup/cost review.
10. Map every lab to current AZ-104 study guide and pass AZ-104.

## Final project
Deploy secure, monitored, cost-controlled Azure environment with identity, network, compute, storage, backup, automation, and troubleshooting evidence; pass AZ-104.

## Completion criteria
- [ ] Can administer identity/RBAC, governance, storage, compute, networking, monitoring.
- [ ] Can troubleshoot VM, permission, network, and storage failures.
- [ ] Can deploy/remove resources with CLI/PowerShell and Bicep.
- [ ] Can explain security, availability, backup, and cost decisions.
- [ ] Pass AZ-104.

## Exam readiness gate
- [ ] Current official exam domains reviewed.
- [ ] Mapped labs completed and documented.
- [ ] Can explain concepts without notes.
- [ ] Weak-area labs repeated without a walkthrough.
- [ ] Practice performance consistently meets personal readiness threshold.
- [ ] Exam version, price, policy, and prerequisites rechecked before booking.

## Cost and safety
Verify regional exam price at checkout. Set cloud budgets before deployment and remove resources afterward. Check OS licensing/evaluation terms. Never expose management services or publish secrets.
