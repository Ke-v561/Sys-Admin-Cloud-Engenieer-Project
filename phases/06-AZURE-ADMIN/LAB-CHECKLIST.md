# Lab checklist — Azure administration

- [ ] Create dedicated subscription/resource group; configure MFA, RBAC, tags, budgets, alerts, and locks.
- [ ] Manage Entra users/groups and assign roles at correct scopes; test least privilege.
- [ ] Build VNets, subnets, peering concepts, NSGs, routes, DNS, and secure connectivity.
- [ ] Deploy/manage VMs, disks, images, extensions, availability, boot diagnostics, and backup.
- [ ] Create storage accounts, Blob/Azure Files, access controls, redundancy, lifecycle, and secure transfer.
- [ ] Configure Azure Monitor, Log Analytics, diagnostics, alerts, resource health, and activity logs.
- [ ] Automate admin tasks with Azure CLI and PowerShell.
- [ ] Deploy resources with Bicep/ARM templates and parameters.
- [ ] Perform backup/recovery test and resource cleanup/cost review.
- [ ] Map every lab to current AZ-104 study guide and pass AZ-104.
