# Phase 06 — AWS Cloud Architecture (Optional Extension)

## Phase purpose
Optional certification phase. After Azure administration and Terraform, a second platform broadens architecture knowledge and shows that cloud concepts transfer across providers. Not required for Azure-focused Cloud Engineer roles.

## Credential and anticipated price
- **Credential:** AWS Certified Solutions Architect — Associate (SAA-C03)
- **Exam price:** $150 USD
- **Price snapshot:** November 5, 2026; before applicable taxes/fees. Confirm current price and exam version before purchase.
- **Other costs:** optional study materials, retakes, and cloud consumption are additional.

## Estimated duration
8–12 weeks at 6–10 study hours per week.

## Starting requirements
- Phases 00–05 complete or equivalent.
- Some hands-on cloud workload design/deployment experience.
- Networking, identity, security, availability, and cost-management fundamentals.

## Phase objectives
- Secure architectures: IAM, secure application tiers, data protection, network controls.
- Resilient architectures: fault tolerance, high availability, backups, recovery, decoupling.
- High-performing architectures: compute, storage, databases, caching, network choices.
- Cost-optimized architectures: pricing, right-sizing, storage tiers, managed services.
- AWS Well-Architected Framework and core service families.

## End goal
Pass SAA-C03 and design a secure, resilient, high-performing, cost-aware AWS solution for a defined business requirement.

## Hands-on work
- Design VPC with public/private subnet layout.
- Design least-privilege IAM roles and policies.
- Compare EC2, containers, and serverless for sample workload.
- Select storage/database services based on requirements.
- Design multi-AZ resilience, backup, and recovery.
- Estimate cost and document security boundaries.
- Optionally deploy a small AWS environment with Terraform.

## Final project
AWS architecture proposal for a fictional business: Well-Architected review, VPC diagram, IAM, compute/storage/database choices, availability, backup, cost estimate, and optional Terraform deployment.

## Completion requirements
- Cover four current SAA-C03 domains.
- Explain service selections and rejected alternatives.
- Complete architecture review and cost estimate.
- Review practice-question rationales.
- 85%+ on fresh practice sets is a readiness heuristic.
- Pass exam and record credential.

## Exam / skills alignment
Current domains: Design Secure Architectures (30%); Design Resilient Architectures (26%); Design High-Performing Architectures (24%); Design Cost-Optimized Architectures (20%). See official guide for task statements.
