# Phase 00 Lab Checklist
- [ ] Inventory host/hypervisor, server/client versions, VM resources, network, IP range, gateway, DNS.
- [ ] Back up anything worth retaining; confirm recovery access before wipe.
- [ ] Reset/reinstall Windows Server; patch and configure hostname/time/static IP.
- [ ] Install AD DS and create test forest/domain.
- [ ] Verify DNS records and name resolution.
- [ ] Create test OUs, users, and groups.
- [ ] Reset/reinstall Windows client and join domain.
- [ ] Verify domain sign-in, DNS, secure channel, and GPO.
- [ ] Snapshot/backup and document recovery.
- [ ] Sanitize evidence before publishing.
