# Phase 08 — Terraform and infrastructure as code

## Purpose
Make infrastructure repeatable and reviewable; deploy to Azure and compare Terraform with Bicep.

## Certification target
**HashiCorp Terraform Associate 004**

## Estimated duration
**6–8 weeks** at 8–10 hours/week, including learning, labs, review, exam preparation, and the exam.

## End goal
Publish sanitized Terraform project deploying/destroying small Azure environment from documented inputs; pass Terraform Associate 004.

## Prerequisites
- Phase 06 complete; basic scripting and Azure administration.

## Official exam objectives
- Terraform Associate 004: https://docs.hashicorp.com/certifications/terraform-associate
- Exam objectives: https://docs.hashicorp.com/terraform/tutorials/certification-004/associate-review-004

## Hands-on lab objectives
1. Install Terraform and configure Azure authentication securely; never hardcode secrets.
2. Write providers, resources, data sources, variables, outputs, locals, expressions, modules.
3. Run fmt/init/validate/plan/apply/destroy; predict changes before apply.
4. Use dependencies, lifecycle rules, custom conditions, and input validation.
5. Understand state, locking, drift, remote state security, workspaces/projects, sensitive values; never commit state.
6. Build reusable module for Azure network and compute/storage.
7. Deploy, modify, destroy, recreate; document failed apply and drift recovery.
8. Compare Terraform and Bicep.
9. Map to Terraform Associate 004 objectives and pass exam.

## Final project
Publish sanitized Terraform project deploying/destroying small Azure environment from documented inputs; pass Terraform Associate 004.

## Completion criteria
- [ ] Can explain IaC and Terraform workflow.
- [ ] Can write reusable configuration with variables, outputs, modules, data sources.
- [ ] Can interpret plan, state, drift, lifecycle.
- [ ] Can protect credentials/state.
- [ ] Can reliably deploy/destroy.
- [ ] Pass Terraform Associate 004.

- [ ] Mapped labs completed and documented.
- [ ] Can explain concepts without notes.
- [ ] Weak-area labs repeated without a walkthrough.

Verify regional exam price at checkout. Set cloud budgets before deployment and remove resources afterward. Check OS licensing/evaluation terms. Never expose management services or publish secrets.
