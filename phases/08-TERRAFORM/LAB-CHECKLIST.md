- [ ] Write providers, resources, data sources, variables, outputs, locals, expressions, modules.
- [ ] Run fmt/init/validate/plan/apply/destroy; predict changes before apply.
- [ ] Use dependencies, lifecycle rules, custom conditions, and input validation.
- [ ] Understand state, locking, drift, remote state security, workspaces/projects, sensitive values; never commit state.
- [ ] Build reusable module for Azure network and compute/storage.
- [ ] Deploy, modify, destroy, recreate; document failed apply and drift recovery.
- [ ] Compare Terraform and Bicep.
- [ ] Map to Terraform Associate 004 objectives and pass exam.
