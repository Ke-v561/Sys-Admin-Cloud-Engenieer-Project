# Phase 03 — Systems administration

## Purpose
Operate Windows servers like an administrator: maintain services, storage, access, patching, monitoring, backups, automation, and incident response.

## End goal
Operate a member/file server with role-based access, patching, monitoring, backup/restore, and PowerShell automation.

## Prerequisites
- Phase 02 complete; ideally enough host RAM/storage for a second server VM. If not, perform the labs on the existing server and document constraints.

## Certification
**None.** No certification required.

## Estimated duration
**4–6 weeks** at 6–10 hours per week. Adjust based on demonstrated competence, not calendar pressure.

## Learning objectives and hands-on labs
1. Add a second Windows Server VM as a member server (if host resources allow).
2. Create an SMB file share; apply share and NTFS permissions using groups; test effective access.
3. Install/configure a server role or service appropriate to the lab and document dependencies.
4. Manage services, scheduled tasks, event logs, performance counters, disk capacity, and remote administration.
5. Apply updates in a maintenance window; document pre-checks, validation, and rollback.
6. Create and restore a backup; verify recovered files and document RPO/RTO.
7. Write PowerShell scripts for user onboarding, inventory, service status, disk alerts, and log collection.
8. Practice incident runbooks: full disk, stopped service, locked account, expired password, failed update, unavailable share.

## Final project
Operate a member/file server with role-based access, patching, monitoring, backup/restore, and PowerShell automation.

## Completion criteria
- [ ] Can explain and test share vs NTFS permissions.
- [ ] Can diagnose service, storage, performance, and update issues.
- [ ] Can run and safely modify PowerShell scripts, explain each command, and handle errors.
- [ ] Can complete a restore and produce an incident report.
