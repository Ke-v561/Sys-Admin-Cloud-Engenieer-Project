# Systems administration lab checklist

- [ ] Build or designate a member/file server.
- [ ] Create SMB share and role-based NTFS/share permissions.
- [ ] Test access with standard, authorized, and unauthorized users.
- [ ] Manage services and scheduled tasks.
- [ ] Review Event Viewer and performance counters.
- [ ] Apply updates with pre-check and post-check records.
- [ ] Configure backup and perform a restore test.
- [ ] Create PowerShell inventory and health-check scripts.
- [ ] Create a disk-space alert or report.
- [ ] Write runbooks for a stopped service, full disk, failed patch, and inaccessible share.
