# Phase 06 — Azure administration

## Purpose
Primary certification and cloud platform phase. Administer Azure identity, governance, compute, storage, networking, and monitoring, then automate common operations.

## End goal
Deploy and operate a secure, monitored, cost-controlled Azure environment using portal and CLI/PowerShell, with at least one Bicep deployment and a documented recovery test.

## Prerequisites
- Phases 01–05 complete; Azure subscription with budget controls. Familiarity with PowerShell and basic networking.

## Certification
**Microsoft AZ-104.** Primary credential for this route. Align every study block to the current official skills outline: https://learn.microsoft.com/credentials/certifications/resources/study-guides/az-104 .

## Estimated duration
**8–12 weeks** at 6–10 hours per week. Adjust based on demonstrated competence, not calendar pressure.

## Learning objectives and hands-on labs
1. Create and secure an Azure account/subscription; configure MFA, RBAC, budgets, alerts, tags, and resource groups.
2. Manage Microsoft Entra users, groups, roles, and hybrid identity concepts; distinguish AD DS from Entra ID.
3. Deploy VMs, disks, images, availability options, extensions, and backup; troubleshoot boot/connectivity.
4. Build VNets, subnets, peering concepts, NSGs, routes, DNS, VPN concepts, and private connectivity designs.
5. Create storage accounts, blob/file storage, access controls, lifecycle, redundancy, and secure data transfer.
6. Configure Azure Monitor, Log Analytics, alerts, diagnostics, and resource health.
7. Use Azure CLI and Azure PowerShell for repeatable administration.
8. Deploy a small resource group using Bicep; parameterize and validate templates.
9. Map each lab to the current official AZ-104 skills outline and revisit weak domains.

## Final project
Deploy and operate a secure, monitored, cost-controlled Azure environment using portal and CLI/PowerShell, with at least one Bicep deployment and a documented recovery test.

## Completion criteria
- [ ] Can administer identity/RBAC, compute, storage, networking, and monitoring independently.
- [ ] Can troubleshoot a failed VM, blocked network path, permissions issue, and storage access issue.
- [ ] Can deploy and remove resources using repeatable scripts/templates.
- [ ] Can explain cost, security, availability, backup, and operational trade-offs.
- [ ] AZ-104 exam readiness is measured against the current official skills outline and practice performance.
