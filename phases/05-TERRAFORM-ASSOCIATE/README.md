# Phase 05 — Infrastructure as Code (Terraform Associate)

## Phase purpose
Certification phase. Learn repeatable infrastructure provisioning, plan review, state management, reusable modules, and version-controlled infrastructure workflows.

## Credential and anticipated price
- **Credential:** HashiCorp Certified: Terraform Associate (004)
- **Exam price:** $70.50 USD plus applicable local taxes/fees; free retake not included.
- **Price snapshot:** November 5, 2026; before applicable taxes/fees. Confirm current price and exam version before purchase.
- **Other costs:** optional study materials, retakes, and cloud consumption are additional.

## Estimated duration
4–8 weeks at 6–10 study hours per week.

## Starting requirements
- Phase 04 complete or equivalent Azure administration experience.
- Basic terminal and Git skills.
- Understanding of cloud resources and networking.

## Phase objectives
- IaC concepts and benefits.
- Providers, resources, data sources, variables, outputs, expressions, functions, dependencies.
- Workflow: init, fmt, validate, plan, apply, destroy.
- Modules and module versioning.
- State, backends, locking, drift, import, state inspection.
- Sensitive values and secret handling.
- HCP Terraform concepts in current objectives.

## End goal
Pass Terraform Associate and create, review, apply, maintain, and destroy cloud infrastructure using version-controlled configuration.

## Hands-on work
- Install Terraform and configure Azure provider securely.
- Deploy resource group, VNet, subnet, NSG, and small compute resource.
- Use variables/outputs and a reusable module.
- Review plan before apply.
- Inspect state and explain why it must be protected.
- Practice drift detection and import in disposable environment.
- Keep code in GitHub; never commit credentials or state.

## Final project
Reusable Terraform project deploying a small Azure environment from code, with variables, module, documented state handling, plan/apply evidence, cost estimate, and safe teardown.

## Completion requirements
- Cover all current Terraform 004 objectives.
- Run fmt, validate, plan, apply, destroy.
- Explain provider, state, modules, dependencies, variables, outputs, sensitive values.
- Demonstrate clean deployment from fresh working directory.
- Review practice questions and weak areas.
- Pass exam and record credential.

## Exam / skills alignment
Official objectives: IaC concepts; Terraform fundamentals; core workflow; configuration; modules; state; maintaining infrastructure; HCP Terraform. Verify live objective list.
