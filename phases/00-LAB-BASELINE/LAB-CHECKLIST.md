# Lab checklist — Lab reset and baseline

- [ ] Record host/hypervisor, VM resources, virtual switches, IPs, DNS, domain, roles, OUs, users/groups, GPOs, shares, DHCP, backups, and recovery credentials.
- [ ] Draw a sanitized network/domain diagram.
- [ ] Confirm console access and a local recovery admin account.
- [ ] Create snapshots/backups and a rollback plan.
- [ ] Create an isolated lab virtual network and test that management/domain services are not internet-exposed.
