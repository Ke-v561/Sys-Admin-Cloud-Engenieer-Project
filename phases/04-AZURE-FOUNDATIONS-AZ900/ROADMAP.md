## Project 4.1 — Design a small-business Azure environment

Create an architecture diagram showing:
- Subscription and resource groups.
- Virtual network and subnet.
- Virtual machine.
- Storage account.
- Microsoft Entra ID and role-based access.
- Monitoring.
- Cost controls.

For this phase, explore the Azure portal and explain each component. Avoid deploying billable resources until pricing and cleanup are understood.
