# Phase 09 — Cloud engineering capstone

## Purpose
Combine the skills into a realistic, documented deployment and operational handoff.

## End goal
Deliver a portfolio-ready cloud environment that another person can deploy, validate, troubleshoot, and tear down using your documentation.

## Prerequisites
- Phases 01–08 complete.

## Certification
**Portfolio assessment.** No certification required.

## Estimated duration
**4–6 weeks** at 6–10 hours per week. Adjust based on demonstrated competence, not calendar pressure.

## Learning objectives and hands-on labs
1. Design a small-business application environment in Azure with identity, network segmentation, compute, storage, monitoring, backup, and least privilege.
2. Deploy the infrastructure using Terraform or Bicep; document decisions and dependencies.
3. Configure logs, metrics, alerts, backup, recovery, and a cost budget.
4. Simulate at least three failures: blocked network, permission denial, and unhealthy/stopped service.
5. Write runbooks, architecture diagram, deployment guide, cleanup guide, and incident reports.
6. Record a short walkthrough explaining design choices, security, cost, failure modes, and how to rebuild.

## Final project
Deliver a portfolio-ready cloud environment that another person can deploy, validate, troubleshoot, and tear down using your documentation.

## Completion criteria
- [ ] A reviewer can reproduce the deployment from the README.
- [ ] All secrets and personal identifiers are removed.
- [ ] Architecture includes identity, networking, compute, storage, monitoring, backup, and cost controls.
- [ ] Three failure scenarios have evidence, root cause, resolution, and prevention.
- [ ] Can explain trade-offs and defend design decisions in an interview.
