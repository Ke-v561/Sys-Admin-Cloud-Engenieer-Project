# Lab checklist — Linux and containers

- [ ] Install Ubuntu Server VM on isolated network; configure hostname, static IP, DNS, SSH.
- [ ] Manage users/groups, sudo, permissions, ACLs, packages, repositories, updates.
- [ ] Manage systemd, scheduled jobs, firewall, storage, mounts, and disk usage.
- [ ] Inspect journalctl and /var/log; troubleshoot boot, DNS, disk, permissions, services.
- [ ] Write shell scripts for inventory, service checks, backup, and log review.
- [ ] Install Docker; build image, run container, inspect logs, map ports, mount volumes, create networks.
- [ ] Apply container security: non-root, minimal image, secret handling, updates, resource limits.
- [ ] Map labs to current Linux+ or RHCSA objectives and pass selected exam.
