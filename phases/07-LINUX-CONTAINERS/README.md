# Phase 07 — Linux and containers

## Purpose
Become comfortable operating Linux workloads because cloud environments are not Windows-only. Learn core administration before containers.

## End goal
Operate a Linux VM and deploy a small containerized service with persistent data and documented network access.

## Prerequisites
- Phases 01–06 complete; ability to create a VM and understand IP/DNS/firewall basics.

## Certification
**None.** No certification required.

## Estimated duration
**4–6 weeks** at 6–10 hours per week. Adjust based on demonstrated competence, not calendar pressure.

## Learning objectives and hands-on labs
1. Install Ubuntu Server VM on an isolated lab network.
2. Manage users/groups, sudo, file permissions, packages, systemd services, SSH keys, firewall, and updates.
3. Inspect logs with journalctl and /var/log; troubleshoot boot, disk, DNS, and service failures.
4. Use shell commands and scripts for inventory, backups, and service checks.
5. Install Docker; build an image, run a container, inspect logs, map ports, mount volumes, and create a custom network.
6. Document image vs container, persistent vs ephemeral data, and basic container security.

## Final project
Operate a Linux VM and deploy a small containerized service with persistent data and documented network access.

## Completion criteria
- [ ] Can connect securely with SSH and administer users/permissions.
- [ ] Can manage services, packages, logs, storage, and networking.
- [ ] Can troubleshoot a failed Linux service.
- [ ] Can build/run/debug a Docker container and explain volumes, ports, and networks.
