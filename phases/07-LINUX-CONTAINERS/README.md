# Phase 07 — Linux and containers

## Purpose
Learn Linux administration and container fundamentals. Choose Linux+ for vendor-neutral certification or RHCSA for practical Red Hat path.

## Certification target
**CompTIA Linux+ (default) OR Red Hat RHCSA (alternative)**

## Estimated duration
**8–10 weeks** at 8–10 hours/week, including learning, labs, review, exam preparation, and the exam.

## End goal
Administer Linux VM and deploy containerized service with persistent data, secure access, and troubleshooting docs; pass Linux+ or RHCSA.

## Prerequisites
- Phase 06 complete; VM, IP, DNS, firewall basics.

## Official exam objectives
- Linux+: https://www.comptia.org/certifications/linux
- RHCSA: https://www.redhat.com/en/services/certification/rhcsa

## Hands-on lab objectives
1. Install Ubuntu Server VM on isolated network; configure hostname, static IP, DNS, SSH.
2. Manage users/groups, sudo, permissions, ACLs, packages, repositories, updates.
3. Manage systemd, scheduled jobs, firewall, storage, mounts, and disk usage.
4. Inspect journalctl and /var/log; troubleshoot boot, DNS, disk, permissions, services.
5. Write shell scripts for inventory, service checks, backup, and log review.
6. Install Docker; build image, run container, inspect logs, map ports, mount volumes, create networks.
7. Apply container security: non-root, minimal image, secret handling, updates, resource limits.
8. Map labs to current Linux+ or RHCSA objectives and pass selected exam.

## Final project
Administer Linux VM and deploy containerized service with persistent data, secure access, and troubleshooting docs; pass Linux+ or RHCSA.

## Completion criteria
- [ ] Can administer users, permissions, packages, services, storage, networking.
- [ ] Can use SSH securely and troubleshoot failures.
- [ ] Can write/explain basic shell scripts.
- [ ] Can build/run/inspect/troubleshoot Docker containers.
- [ ] Pass selected Linux credential.

## Exam readiness gate
- [ ] Current official exam domains reviewed.
- [ ] Mapped labs completed and documented.
- [ ] Can explain concepts without notes.
- [ ] Weak-area labs repeated without a walkthrough.
- [ ] Practice performance consistently meets personal readiness threshold.
- [ ] Exam version, price, policy, and prerequisites rechecked before booking.
