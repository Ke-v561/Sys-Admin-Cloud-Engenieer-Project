# Kev.exe — Hands-On IT & Cloud Engineering Academy

This is a guided training program built around **specific objectives, step-by-step labs, expected results, troubleshooting, and portfolio evidence**.

## How to use a project
1. Read the objective and prerequisites.
2. Follow every numbered step yourself.
3. Compare actual results with expected results.
4. If something fails, record the error before changing anything.
5. Save sanitized notes, screenshots, diagrams, or scripts.
6. Complete the acceptance checklist and knowledge check.
7. Commit your work to your own copy of this repository.

## Safety rules
- Start with free/local tools. Research pricing before creating cloud resources.
- Never publish passwords, tokens, private keys, personal information, or unredacted screenshots.
- Use only systems you own or are authorized to administer.
- Do not run destructive commands on work or production systems.
- If the screen differs from the instructions, record the exact message and pause rather than guessing.
