# 04 — PowerShell & IT Automation

**Prerequisite:** basic Windows navigation and comfort using a test environment.

## Learn in order
- [ ] Run commands and discover help with `Get-Help`, `Get-Command` and `Get-Member`.
- [ ] Understand variables, strings, arrays, hashtables, conditionals and loops.
- [ ] Understand objects, pipelines, filtering and sorting.
- [ ] Read and write CSV files; learn functions, parameters and reusable code.
- [ ] Add validation, error handling, logging and useful exit messages.
- [ ] Learn safe handling of credentials and why secrets should not be hard-coded.

## Projects
- [ ] **Project A: System inventory** — collect basic OS, hostname, disk and memory information from your own test machine; export a CSV report.
- [ ] **Project B: Log/report helper** — parse a sample or sanitized log and summarize selected events.
- [ ] **Project C: Account audit** — process a fictional CSV of users and flag missing fields or duplicate entries; do not modify real accounts.
- [ ] **Project D: Lab health check** — check selected services, disk space and connectivity and produce a readable report.

## Quality gates
- [ ] Test normal, missing-input and invalid-input cases.
- [ ] Add comments and a README with prerequisites, usage, expected output and limitations.
- [ ] Store sample input only; exclude secrets and real personal data.
- [ ] Include a troubleshooting section and one known limitation per project.

## Certification milestone
This path is primarily skills-first. After reviewing target job descriptions, choose a relevant current certification rather than forcing an unrelated exam. Continue toward AZ-104 for Azure administration or a role-aligned Windows/automation credential where available.
