# 06 — AWS Foundations (Optional)

**Prerequisite:** cloud fundamentals. This path is optional; prioritize AWS if it appears in jobs you want.

## Learn
- [ ] AWS global infrastructure: Regions and Availability Zones.
- [ ] IAM users, roles, policies and least privilege.
- [ ] Core services: EC2, S3, VPC, security groups, CloudWatch and billing tools.
- [ ] Shared responsibility, high availability, resilience, security and cost optimization.
- [ ] Compare AWS concepts with equivalent Azure concepts.

## Build
- [ ] Draw a fictional small-business AWS architecture.
- [ ] Explain the purpose and security boundaries of each service.
- [ ] If deploying resources, check current pricing, set billing alerts, use minimal resources and delete them immediately after testing.
- [ ] Publish a design, threat considerations, cost assumptions and cleanup checklist.

## Certification finish line
- [ ] Review the current official exam guide and AWS Skill Builder learning material.
- [ ] Complete practice assessments.
- [ ] Earn **AWS Certified Cloud Practitioner** if it aligns with your target roles; consider an associate-level certification later if AWS is a major career focus.

Official certification page: https://aws.amazon.com/certification/certified-cloud-practitioner/
