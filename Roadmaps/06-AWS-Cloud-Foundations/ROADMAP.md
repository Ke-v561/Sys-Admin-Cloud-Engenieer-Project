# Roadmap 06 — AWS Cloud Foundations

**Outcome:** Explain AWS identity, compute, storage, networking, monitoring, and cost, then complete a controlled lab if account eligibility and cost controls are clear.

## Project 01 — Service Map & Account Safety
1. Define Region and Availability Zone using official AWS documentation.
2. Explain IAM, EC2, S3, VPC, CloudWatch, and billing tools in your own words.
3. Draw a fictional architecture with VPC, subnet, EC2, and S3; mark security boundaries.
4. Explain root-user protection, MFA, and least privilege.
5. Do not launch billable resources for this project.
**Deliverable:** Service map and safety checklist.

## Project 02 — IAM Design
1. Create a fictional team and list what each role needs to do.
2. Design least-privilege permissions on paper.
3. Explain the difference between identity, policy, and permission scope.
4. Use official training/sandbox resources; do not weaken protections on an account you depend on.
**Deliverable:** IAM role matrix.

## Project 03 — Compute & Storage
1. Choose a fictional workload and explain whether EC2 and/or S3 fits.
2. Draw the data flow and security boundaries.
3. Check current pricing and cleanup steps before any deployment.
**Deliverable:** Architecture and service-selection rationale.

## Project 04 — VPC Networking
1. Draw a VPC with public/private subnet concepts.
2. Annotate route tables, internet gateway, and security groups.
3. Trace an example request path and explain where traffic should be allowed or blocked.
**Deliverable:** Annotated network diagram.

## Project 05 — Billing, Monitoring & Certification Readiness
1. Explain cost visibility, budgets/alerts, and resource cleanup.
2. Create a preflight/cleanup checklist.
3. Compare current AWS Certified Cloud Practitioner exam objectives with your notes.
4. Take practice questions and document missed objectives.
**Optional certification:** AWS Certified Cloud Practitioner if relevant to target roles. Verify current exam details with AWS before booking.
