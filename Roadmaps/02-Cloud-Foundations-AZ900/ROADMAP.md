# 02 — Cloud Foundations → AZ-900

**Prerequisite:** Path 01 completed. No prior cloud experience required.

## Learn
- [ ] Explain cloud computing and why organizations use it.
- [ ] Compare public, private and hybrid cloud.
- [ ] Compare IaaS, PaaS and SaaS with examples.
- [ ] Understand shared responsibility, high availability, scalability, elasticity and disaster recovery.
- [ ] Learn core Azure building blocks: regions, availability zones, resource groups, subscriptions and management groups.
- [ ] Learn identity, access control, security posture, governance, compliance and cost management at a fundamentals level.
- [ ] Understand pricing factors, budgets and why deleting resources matters.

## Build
- [ ] Draw a simple fictional company's cloud architecture.
- [ ] Map example services to compute, networking, storage, identity and monitoring.
- [ ] Create a cloud-vs-on-premises comparison with cost, security and operational trade-offs.
- [ ] Use official Microsoft Learn material and the current AZ-900 study guide to check coverage.

## Evidence
- [ ] Publish `cloud-architecture.md` and an architecture diagram.
- [ ] Include a glossary in your own words and 10 practice questions you missed, with corrections.
- [ ] Do not create billable Azure resources just to pass AZ-900; use learning material and sandbox options when available.

## Certification finish line
- [ ] Review the current official AZ-900 exam objectives.
- [ ] Complete practice assessments and explain why each answer is right or wrong.
- [ ] Book and pass **Microsoft Certified: Azure Fundamentals (AZ-900)** when ready.

Official study guide: https://learn.microsoft.com/credentials/certifications/resources/study-guides/az-900
