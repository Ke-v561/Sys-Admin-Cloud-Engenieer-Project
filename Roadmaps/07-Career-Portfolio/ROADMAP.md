# Roadmap 07 — Career Portfolio

## Project 01 — Portfolio Index
1. Add a section to the repository README for each completed project.
2. For each, state the problem, tools, skills demonstrated, and link to evidence.
3. Label work honestly: completed independently, completed with a guide, or still in progress.
**Deliverable:** A readable portfolio index.

## Project 02 — Technical Case Study
1. Select a completed project.
2. Write the problem statement and requirements.
3. Add a diagram and implementation steps.
4. Include test results, troubleshooting, and limitations.
5. Remove credentials, customer/employer data, host identifiers, and sensitive network details.
**Deliverable:** One polished case study.

## Project 03 — Skills-to-Job Matrix
1. Review 5–10 current job descriptions for target roles.
2. List recurring skills and tools.
3. Map each skill to a project or label it “learning” / “not yet demonstrated.”
4. Choose the next project based on gaps.
**Deliverable:** Skills matrix.

## Project 04 — Interview Practice
1. For each project, explain the goal, design choice, test, failure, fix, and lesson learned aloud.
2. Record a concise STAR story for troubleshooting and automation.
3. Identify claims you cannot yet support with evidence and revise your resume accordingly.
**Deliverable:** Project-based interview notes.
