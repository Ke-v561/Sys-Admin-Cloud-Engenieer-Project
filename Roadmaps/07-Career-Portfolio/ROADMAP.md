# 07 — Career Portfolio

This path runs alongside the technical roadmaps. Update it whenever you finish a meaningful lab or project.

## Build your evidence
- [ ] Keep each project README clear: problem, goals, architecture, prerequisites, steps, tests, troubleshooting, outcome and lessons learned.
- [ ] Add sanitized screenshots, diagrams and sample outputs.
- [ ] Maintain a skills matrix with columns for skill, learning status, project evidence and confidence.
- [ ] Maintain a list of technical problems solved and explain each using situation, action and result.
- [ ] Never claim production experience based only on a home lab; label lab projects honestly.

## Connect work to roles
- [ ] Collect 10 job descriptions for Systems Administrator, Infrastructure Support and Junior Cloud Administrator roles.
- [ ] Record repeated requirements and map them to roadmap tasks.
- [ ] Update resume bullets only when you have evidence to support them.
- [ ] Practice explaining one project in 2 minutes, then in 10 minutes with technical detail.
- [ ] Revisit certification priorities based on current job requirements and official vendor catalogs.

## Completion milestone
You can demonstrate at least three documented projects, describe the decisions and trade-offs, troubleshoot a failure, and map your skills to the requirements of your target roles.
