# 03 — Windows Systems Administration

**Prerequisite:** Path 01. AZ-900 is recommended but not mandatory before beginning.

## Phase 1 — Windows administration basics
- [ ] Learn local accounts, groups, file permissions, services, processes, logs, updates and remote access.
- [ ] Practice PowerShell and GUI tools on a test VM, not a work device.
- [ ] Troubleshoot a deliberately stopped noncritical service and document the recovery.

## Phase 2 — Server and networking services
- [ ] Learn the purpose of Windows Server and server roles.
- [ ] Explain DNS, DHCP, IP addressing, name resolution and time synchronization.
- [ ] Learn the purpose of Active Directory Domain Services (AD DS), domains, organizational units, users and groups.
- [ ] Learn Group Policy and least-privilege access.
- [ ] Learn backup, restore, patching, monitoring and basic incident documentation.

## Phase 3 — Build the portfolio lab
- [ ] Plan a small fictional organization with an administrator and several test users.
- [ ] Build a Windows Server lab using evaluation/licensed software and hardware that meets requirements; if not feasible, create a design and use a guided sandbox.
- [ ] Configure a domain only in an isolated lab network.
- [ ] Create test users/groups and apply a basic Group Policy.
- [ ] Test sign-in, permissions and name resolution.
- [ ] Back up or checkpoint the lab and test a recovery procedure.
- [ ] Troubleshoot one planned failure and document root cause and fix.

## Evidence
- [ ] Publish a network diagram, build steps, sanitized screenshots, test cases and troubleshooting log.
- [ ] Never use real employer accounts, data, domain names or credentials.

## Certification milestone
- [ ] Review Windows/System Administrator job postings and identify the certification most commonly requested.
- [ ] Check Microsoft's current certification catalog before choosing an exam; do not assume a retired Windows Server exam is still available.
