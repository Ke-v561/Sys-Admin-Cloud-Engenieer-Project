# 05 — Azure Administration → AZ-104

**Prerequisites:** Path 01 and Path 02 recommended; Path 04 PowerShell is helpful. AZ-900 is recommended.

## Learn
- [ ] Azure identity and governance: Microsoft Entra ID, role-based access control, subscriptions, resource groups, policy and locks.
- [ ] Storage: accounts, redundancy, access methods and lifecycle basics.
- [ ] Compute: virtual machines, sizing, disks, availability and lifecycle management.
- [ ] Networking: virtual networks, subnets, NSGs, DNS and connectivity concepts.
- [ ] Monitoring, alerts, backup, recovery and resource health.
- [ ] Use PowerShell/CLI for repeatable administration where appropriate.

## Cost and security gate — before deploying resources
- [ ] Review current Azure pricing and free-account terms.
- [ ] Configure budgets/alerts where available; understand that alerts are not necessarily hard spending caps.
- [ ] Use least privilege and MFA.
- [ ] Create only the resources needed for a lab, record their names, and delete them when finished.
- [ ] Never upload secrets or credentials to GitHub.

## Portfolio project: secure small-business Azure environment
- [ ] Write requirements for a fictional small business.
- [ ] Design resource groups, identity/access, network, compute and storage.
- [ ] Deploy a minimal environment only after estimating cost and confirming the lab is affordable.
- [ ] Test access controls, network rules, monitoring and cleanup.
- [ ] Document architecture, decisions, test evidence, estimated costs and teardown steps.
- [ ] Where possible, include repeatable deployment commands/templates without embedded secrets.

## Certification finish line
- [ ] Follow the current official AZ-104 study guide and map each objective to a lab or explanation.
- [ ] Complete practice assessments and revisit weak areas.
- [ ] Book and pass **Microsoft Certified: Azure Administrator Associate (AZ-104)** when ready.

Official study guide: https://learn.microsoft.com/credentials/certifications/resources/study-guides/az-104
