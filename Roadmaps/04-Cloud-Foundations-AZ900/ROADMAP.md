# Roadmap 04 — Cloud Foundations / AZ-900

**Outcome:** Explain cloud models, Azure architecture/services, security, governance, and cost without needing to deploy paid resources.

## Project 01 — Cloud Model Comparison
1. Make a table: scenario, deployment model, service model, reason, trade-off.
2. Classify these scenarios: hosted email/collaboration; a VM where you control the OS; a legacy local system connected to cloud services; deploying code while provider manages the runtime.
3. Explain one trade-off for each choice.
4. Verify terms against the current official AZ-900 study guide.
**Deliverable:** `cloud-models.md`.

## Project 02 — Azure Architecture Map
1. Define region, availability zone, subscription, resource group, and resource.
2. Draw a fictional small-business Azure layout using these concepts.
3. Label which objects contain or organize other objects.
4. Explain why a resource group is not the same thing as a subscription.
**Deliverable:** Diagram plus explanation.

## Project 03 — Core Service Selection
1. Create columns for compute, networking, storage, identity, database, monitoring.
2. Map each category to one or more Azure services.
3. Match three fictional business needs to service categories and explain why.
4. Avoid claiming a service is free unless verified.
**Deliverable:** Service mapping worksheet.

## Project 04 — Security, Governance & Cost
1. Explain shared responsibility.
2. Explain identity, RBAC, tags, resource locks, and cost management at a high level.
3. Create a fictional pre-deployment checklist: permissions, region, pricing, budget/alert availability, cleanup.
4. Note that budgets/alerts may notify rather than hard-stop spending.
**Deliverable:** Security/cost checklist.

## Project 05 — AZ-900 Exam Readiness
1. Open Microsoft’s current AZ-900 study guide.
2. Map each exam objective to notes or a project artifact.
3. Take a reputable practice assessment.
4. Record every missed objective and review it.
5. Repeat until results are consistently strong and you can explain the answers.
**Final milestone:** AZ-900. Verify current objectives and exam details with Microsoft before booking.
