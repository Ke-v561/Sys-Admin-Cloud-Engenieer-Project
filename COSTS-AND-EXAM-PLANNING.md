# Cost and exam planning

- Verify all exam versions, prerequisites, and regional prices before booking.
- Microsoft currently lists AZ-802, AZ-104, and AZ-400 at $165 USD for US-region exams.
- HashiCorp lists Terraform Associate 004 at $70.50 USD plus applicable taxes/fees.
- CompTIA and AWS prices vary; use provider checkout for current price.
- Budget separately for practice exams, retakes, books, OS licensing, and cloud usage.
- Check employer reimbursement before paying.
- Set Azure budgets/alerts and delete resources after labs.
- Keep a retake reserve; avoid purchasing multiple overlapping courses.
