# Phase exit rubric

Score each capability:
- **0 — Not attempted**
- **1 — Can follow a tutorial**
- **2 — Can complete with notes and occasional help**
- **3 — Can complete independently and explain why**
- **4 — Can troubleshoot variations, document it, and teach someone else**

A phase is complete when every required exit criterion scores at least 3 and the final project is documented. Any critical safety or security criterion must score 4 before using the technique outside the lab.
