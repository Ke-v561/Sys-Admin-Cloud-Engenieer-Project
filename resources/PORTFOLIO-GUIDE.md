# Portfolio guide

Publish sanitized evidence: network diagrams, subnetting workbook, AD DS design, OU/group/GPO results, DNS troubleshooting, backup/restore report, file-server permissions matrix, PowerShell scripts, security baseline, Azure architecture, RBAC matrix, monitoring/backup evidence, Linux/Docker deployment, Terraform modules, capstone runbooks, and failure reports.

Each project should explain the problem, requirements, design, implementation, security, validation, troubleshooting, cost, cleanup, and lessons learned. Never publish exam dumps or copied proprietary course content.
