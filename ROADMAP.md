# Master Roadmap | Kev.exe

## Career destination

Progress toward these roles in sequence, based on demonstrated skills and employer requirements:

1. Systems Administrator I / Junior Systems Administrator
2. IT Infrastructure Analyst / Infrastructure Support Engineer
3. Cloud Support Engineer / Azure Support Administrator
4. Azure Administrator / Cloud Operations Engineer
5. Junior Cloud Engineer
6. Cloud Engineer / Cloud Infrastructure Engineer (longer-term)

Certifications support this progression; they do not replace hands-on experience.

## Timeline estimate

Planning estimate: **9–12 months at 6–8 hours per week**. Adjust the pace based on mastery, work/family schedule, and lab availability.

## Phase gates

### Gate A — Systems foundation
You can explain how a Windows endpoint obtains an IP address, resolves DNS, authenticates to a domain, and reaches a network resource. You have built and troubleshot a small Windows domain.

### Gate B — Automation foundation
You can read, modify, test, and explain PowerShell scripts. You can collect system information, test connectivity, and export a report.

### Gate C — Azure administrator
You can create and manage a resource group, identity permissions, virtual network, VM, storage, monitoring, and a safe cleanup process. You can troubleshoot access and connectivity failures.

### Gate D — Multi-cloud and operations
You can map Azure concepts to AWS, explain IAM/VPC/EC2/S3/CloudWatch, investigate incidents, plan backup/recovery, and reason about cloud costs.

### Gate E — Job-ready portfolio
You have three or more end-to-end projects with architecture, implementation, validation, troubleshooting, and sanitized evidence.

## Career application checkpoints

Do not wait for all four certifications.

- After Phase 2: consider Junior Systems Administrator and IT Infrastructure Support roles.
- After Phase 3: add Systems Administrator I and Technical Support Engineer roles where PowerShell is relevant.
- During Phase 5: begin targeting Cloud Support and Azure Support roles if you can demonstrate the work.
- After Phases 7–8: broaden toward Cloud Operations and Junior Cloud Engineer roles where experience requirements fit.
