# Kev.exe Master Roadmap — Fresh Start

## Goal
Build from no cloud or home-lab experience toward Systems Administration and Cloud Administration, using practical projects and certifications as milestones.

## Follow this order

- [ ] **01. Foundations & First Lab** — understand your computer, virtualization, networking basics and safe lab practices; create your first documented lab.
- [ ] **02. Cloud Foundations** — learn cloud concepts, identity, security, governance and pricing; prepare for and earn AZ-900.
- [ ] **03. Windows Systems Administration** — practice Windows administration, local users, permissions, DNS/DHCP concepts, Active Directory and Group Policy in a controlled lab.
- [ ] **04. PowerShell & IT Automation** — learn shell fundamentals and build tested IT support scripts.
- [ ] **05. Azure Administration** — practice identity, governance, compute, networking, storage, monitoring and cost controls; prepare for and earn AZ-104.
- [ ] **06. AWS Foundations (optional)** — study AWS only if it aligns with target jobs; consider AWS Certified Cloud Practitioner.
- [ ] **07. Career Portfolio** — publish project evidence, map skills to job descriptions, and prepare interview stories.

## Rules for progressing

A lesson watched is not completion. Complete the lab, verify the result, explain it in your own words, document troubleshooting and publish safe evidence. Review official exam objectives before booking any exam. Certification names, objectives and availability can change, so verify vendor pages at the time of study.
