# Roadmap and timetable

Assumes 8–10 hours/week, including learning, labs, exam preparation, and exam scheduling.

| Phase | Certification | Duration |
|---|---|---:|
| 00 — Lab baseline | None | 1 week |
| 01 — Networking | Network+ N10-009 | 6–8 weeks |
| 02 — Windows Server & AD DS | AZ-802 prep, part 1 | 6–8 weeks |
| 03 — Systems administration | AZ-802 prep, part 2; sit exam | 5–7 weeks |
| 04 — Cloud fundamentals | AZ-900 | 3–4 weeks |
| 05 — Security foundations | Security+ | 6–8 weeks |
| 06 — Azure administration | AZ-104 | 12–16 weeks |
| 07 — Linux and containers | Linux+ | 8–10 weeks |
| 08 — Infrastructure as code | Terraform Associate 004 | 6–8 weeks |
| 09 — Cloud engineering specialization | AZ-400 or AZ-305 | 8–10 weeks |
| 10 — AWS extension (optional) | SAA-C03 | 8–12 weeks |

Core path: 61–80 weeks of planned study, approximately 14–19 months, with a practical allowance of **15–20 months** for breaks, scheduling, and review. AWS adds 8–12 weeks; practical total approximately **17–23 months**.

## Credential choices
- Network+ is the default; choose CCNA instead for deeper Cisco networking.
- AZ-802 is one exam for Windows Server Administrator Associate, prepared across Phases 02 and 03.
- Linux+ is the default; RHCSA is an alternative.
- AZ-400 targets DevOps delivery/automation. AZ-305 targets solution architecture. Choose one and verify current prerequisites before booking.
- AWS SAA-C03 is optional and should follow the Azure capstone.

## Lab growth
1. Inventory current Windows Server DC and joined client.
2. Add a member/file server VM and second client only if resources allow.
3. Add Ubuntu Server for Linux and Docker labs.
4. Use Azure only with budget, alerts, resource tags, and teardown checklist.
5. Buy hardware only after measuring actual CPU/RAM/storage limits.

## Phase gate
Move on only when mapped labs are repeatable, the project is documented, and you can explain and troubleshoot the configuration. Certification readiness is an additional gate.
