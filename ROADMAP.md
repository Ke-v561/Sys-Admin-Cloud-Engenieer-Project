# Master Roadmap — Kev.exe

## What counts as complete?
A project is complete only when you performed the lab, verified the result, documented what happened, removed sensitive information, and can explain the result without simply reading the instructions.

| Path | Practical outcome | Portfolio evidence | Certification milestone |
|---|---|---|---|
| 01. IT Fundamentals & Networking | Inspect a Windows system and troubleshoot basic network/DNS issues | Inventory and troubleshooting reports | No cert required |
| 02. Windows Systems Administration | Build and manage a small isolated Windows domain | Lab diagram, AD users/groups, GPO test and troubleshooting report | Select a current credential after checking job requirements |
| 03. PowerShell & Automation | Write safe scripts that collect and report system data | Commented scripts, tests, sample outputs | Supports administrator/cloud certifications |
| 04. Cloud Foundations | Explain cloud models, Azure services, security, and cost | Service mapping and architecture worksheet | AZ-900 |
| 05. Azure Administration | Plan, secure, monitor, and clean up Azure resources | Documented Azure lab and cleanup evidence | AZ-104 |
| 06. AWS Cloud Foundations | Explain IAM, compute, storage, VPC, monitoring, and billing | AWS service map and controlled lab plan | Cloud Practitioner if useful for target roles |
| 07. Career Portfolio | Present technical work credibly | Project index, case studies, interview stories | Ongoing |

Recommended order: 01 → 02 → 03 → 04/AZ-900 → 05/AZ-104 → 06 if relevant → 07 continuously.
